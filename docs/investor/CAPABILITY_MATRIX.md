## Maintain the evidence

Review source and backlog before changing a claim. Update JSON explicitly, then run `node scripts/pilot-evidence.mjs --write` and `npm run check:pilot-evidence`. The check rejects unsupported current claims, unknown backlog IDs, missing source files and stale generated output (LF/CRLF materialization is equivalent). It checks traceability, not runtime behavior or semantic completeness. Required release/CI must still pass.

Read the [architecture/security overview](ARCHITECTURE_SECURITY_OVERVIEW.md), [pilot gates](../pilot-gates.json), [backlog](../DELIVERY_BACKLOG.md) and [risk register](../RISK_REGISTER.md) before presenting pilot readiness.
